# Datos

- `derived/`: tablas resumen por individuo, sin coordenadas (bitácora de limpieza, variogramas, colas inmóviles y cortes posliberación).
- `raw/` (ignorado por git): exportación de Movebank (610 504 filas, 72 individuos), Darwin Core y capas SIG (AMVA, SIDAP, WorldCover, DEM). Las ubicaciones de fauna son sensibles y no se versionan; la fuente es Movebank y la carpeta de Drive del proyecto.
