## Estructura del repositorio
- `ESQUEMA.md` — índice, presupuesto de páginas y normas que soportan cada sección (IDs del registro).
- `secciones/` — un archivo Markdown por sección.
- `registro/` — registro normativo y bibliográfico (Excel). Ninguna norma se cita si no está "Verificado" o, como mínimo, "Vigencia verificada".
- `figuras/` — flujogramas y tablas.
- `PENDIENTES.md` — verificaciones abiertas y decisiones.

## Convenciones de redacción
- `[N07]`, `[L01]`: ID del registro que sustenta la afirmación. Se reemplazan por la cita APA en la versión final.
- `> ⚠️ ZONA GRIS:` asunto normativo con interpretación dudosa; se marca para revisión jurídica.
- `> 🗣️ TESTIMONIO (por conseguir):` recuadro para la experiencia de un investigador, consultor o funcionario.
- `[VERIFICAR]`: dato que aún no tiene soporte confirmado. No puede quedar ninguno en la versión entregada.
